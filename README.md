# Trabajo-Grupal-Programación-I

## Integrantes
Jerónimo Genero, Juan Bautista García Fava.

## Descripcion del programa
Programa para administrar los servicios de un service de autos. El programa permite:
- Agregar órdenes de servicio.
- Mostrar el listado completo.
- Mostrar servicios pendientes.
- Buscar servicios por patente.
- Separar servicios finalizados y pendientes.
